# 🚀 新品制造机 — 全链路新品孵化决策引擎

医用美护行业的新品孵化工具集，覆盖品类分析、智能定价、营销方案设计三大核心环节。

## 📁 项目结构

```
新品网站/
├── 设计稿1.html        # 🏠 工作台主页（导航中枢）
├── category_map.html   # 🗺️ 品类地图（商品矩阵可视化 + AI 分类）
├── pricing.html        # 💲 智能定价（采购价 + 前台价计算）
└── agent.html          # 🤖 AI 营销助手（打爆方案生成）
```

## 🏠 设计稿1.html — 工作台概览

项目的导航中枢，提供全局态势感知和快捷入口。

**功能：**
- **KPI 仪表盘**：孵化中新品数、已上市新品数、累计 GMV、爆品率、孵化成功率、参与品类数
- **快捷入口卡片**：品类地图分析、智能定价、打爆方案、销售复盘（外部链接）
- **品类地图预览区**：嵌入式品类概览数据
- **侧边栏导航**：统一的项目内页面跳转

**技术栈：** 纯 HTML/CSS（暗色科技风主题），无外部依赖

## 🗺️ category_map.html — 品类地图

将商品数据按双维度（纵轴 × 横轴）进行矩阵可视化，支持 Excel/JSON 导入导出。

**核心功能：**

| 功能 | 说明 |
|------|------|
| 数据导入 | 上传 Excel（.xlsx/.xls）或 JSON，自动解析 SKU 名称、品牌、价格、成交金额 |
| 纵轴维度 | 价格带（6档：低价→超高）或销售占比（8档：极低→顶流） |
| 横轴维度 | 品牌 / **AI 智能分类**（DeepSeek 提取 Top 10 关键词，按销售额占比降序排列） |
| 占比标注 | 每行/每列标题自动显示该维度销售额占总成交额的百分比（保留两位小数） |
| 折叠展开 | 单元格内多商品时默认展示首个，点击按钮展开全部 |
| 数据导出 | 支持下载 JSON / 导出 CSV |
| 关键词词典 | 可编辑的成分/形态/功效匹配词库，用于 Excel 导入时的自动分类 |

**AI 集成（DeepSeek）：**
- 用户输入分类维度关键词（如"成分""形态""功效""适用肤质"）
- DeepSeek 分析全部 SKU 名称，提取前 10 个高频关联分类词
- 自动归类每个 SKU，切换横轴为 AI 分类结果
- System prompt 内置医用美护行业归类规则（形态归并、成分合并）

**外部依赖：**
- SheetJS (`xlsx.full.min.js`) — Excel 解析
- DeepSeek Chat API — AI 关键词提取

## 💲 pricing.html — 智能定价

新品定价策略工具，分两个模块。

**模块一：采购价计算器**
- 输入：预计前台毛利率（含最低/最高）、平台价
- 输出：采购价建议最低价 / 建议价 / 最高价
- 公式：`采购价 = (1 − 毛利率) × 平台价`

**模块二：前台价智能计算**
- 上传与品类地图相同格式的 Excel
- 自动从 SKU 名称中提取关键词（成分/形态/功效词典匹配）
- 用户勾选目标关键词 → 计算匹配 SKU 的「件单价-成交」均值作为建议前台价
- 展示匹配 SKU 数量和详细来源

**外部依赖：**
- SheetJS (`xlsx.full.min.js`) — Excel 解析

## 🤖 agent.html — AI 营销助手

基于 DeepSeek 的对话式营销策略顾问，专注于新品打爆方案设计。

**功能：**
- 💬 对话式交互界面，支持历史记录
- 🎯 预设提示词模板（快速启动常见场景）
- ⚙️ 可配置设置面板：
  - API 地址 / Endpoint / 模型名称
  - Temperature / Max Tokens
  - 自定义 System Prompt
  - WebSocket 端口（流式传输预留）
- 💾 设置持久化到 localStorage
- 🔌 一键测试 API 连接状态
- 📝 对话清空功能

**System Prompt 身份：** 医用美护采销专家，内置形态/成分归类规则知识

**外部依赖：**
- DeepSeek Chat API（兼容 OpenAI 格式的 `/v1/chat/completions` 端点）

## 🔑 API Key 配置

- **category_map.html**：在第 342 行直接填写 DeepSeek API Key：
  ```javascript
  let deepseekApiKey = 'sk-xxxxxxxxxxxxxxxxxxxxxxxx';
  ```
- **agent.html**：在设置面板（⚙️）中输入，或代码第 252 行 `Authorization` header 中直接替换

## 🎨 设计风格

- 暗色科技风主题（`#0A1628` 底色，`#1A5CFF` 品牌蓝）
- 统一的视觉语言：渐变发光、毛玻璃卡片、微交互动画

## 📊 数据流

```
Excel 上传 → SheetJS 解析 → 关键词匹配归类 → 产品数据模型
                                              ├─→ 品类地图矩阵渲染
                                              ├─→ 行/列销售额占比计算
                                              └─→ AI 关键词提取（DeepSeek）

产品数据模型 → JSON/CSV 导出 → 下游分析复用
```
